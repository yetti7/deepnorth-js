# Deep North

The static landing page for deepnorth.app, written in plain HTML and CSS.
No JavaScript, package installation, or build step is required.

Cloudflare Pages serves the contents of `public/`. Use the **None** framework
preset, `exit 0` as the no-op build command, and `public` as the output directory.

For a local preview, open `public/index.html` or serve `public/` with any static
HTTP server.
